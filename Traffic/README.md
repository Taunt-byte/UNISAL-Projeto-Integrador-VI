# NetMonitor — aplicação web

Veja o [README principal](../README.md) para a descrição completa.

```bash
pip install -r requirements.txt
python app.py            # só neste computador
python app.py --rede     # outros dispositivos da rede também acessam
```

Para zerar os dados, apague `pythonsqlite.db` (ele é recriado sozinho).
